SW-12 — Acceso Santo Domingo

AEGIS SOLUTIONS
Configuración del switch de acceso correspondiente a la sede de Santo Domingo.

📋 Información general
Parámetro	Valor
Dispositivo	SW-12
Rol	Switch de acceso
Ubicación	Santo Domingo
Dominio	aegis.com.do
SSH	Versión 2
Spanning Tree	Rapid-PVST
VLAN nativa	VLAN 99

🔐 1. Configuración básica y seguridad

Se configura el nombre del dispositivo, autenticación administrativa, dominio, SSH y cifrado de contraseñas.

enable
configure terminal

hostname SW-12

service timestamps debug datetime msec
service timestamps log datetime msec
service password-encryption

enable secret AEGIS-2026

username admin privilege 15 secret AEGIS-2026

no ip domain-lookup
ip domain-name aegis.com.do

ip ssh version 2
ip ssh time-out 60

crypto key generate rsa modulus 2048

🛡️ 2. Compatibilidad DHCP / IOL / PNETLab

Se deshabilitan determinadas funciones para evitar problemas de compatibilidad con el entorno de laboratorio IOL/PNETLab.

no ip dhcp snooping
no ip dhcp snooping information option
no ip arp inspection vlan 50,60,70,99

🏢 3. VLANs locales

El switch utiliza cuatro VLANs:

VLAN	Nombre	Función
50	FINANZAS	Departamento de Finanzas
60	VENTAS	Departamento de Ventas
70	MARKETING	Departamento de Marketing
99	NATIVA	VLAN nativa de los enlaces troncales
Configuración
vlan 50
 name FINANZAS

vlan 60
 name VENTAS

vlan 70
 name MARKETING

vlan 99
 name NATIVA

exit

🌳 4. Spanning Tree

Se utiliza Rapid-PVST para mejorar la convergencia de la red ante cambios en la topología.

spanning-tree mode rapid-pvst
spanning-tree extend system-id

🔗 5. Enlaces troncales

Los puertos Ethernet0/0 y Ethernet0/1 funcionan como enlaces troncales hacia los switches multicapa SWM-1 y SWM-2.

Características
Protocolo: 802.1Q
VLANs permitidas: 50,60,70,99
VLAN nativa: 99
DTP: deshabilitado
Estado: habilitado
Configuración
interface range Ethernet0/0 - 1

description UPLINKS-MULTICAPA

switchport trunk encapsulation dot1q
switchport trunk allowed vlan 50,60,70,99
switchport trunk native vlan 99
switchport mode trunk
switchport nonegotiate

no shutdown

💻 6. Puertos de acceso
Ethernet0/2 — Finanzas

Este puerto conecta el equipo correspondiente al departamento de Finanzas mediante la VLAN 50.

interface Ethernet0/2

description PC_FINANZAS

switchport access vlan 50
switchport mode access
switchport nonegotiate

switchport port-security
switchport port-security maximum 2
switchport port-security violation restrict
switchport port-security mac-address sticky

spanning-tree portfast edge
spanning-tree bpduguard enable

no shutdown
Ethernet0/3 — Ventas

Este puerto conecta el equipo correspondiente al departamento de Ventas mediante la VLAN 60.

interface Ethernet0/3

description PC_VENTAS

switchport access vlan 60
switchport mode access
switchport nonegotiate

switchport port-security
switchport port-security maximum 2
switchport port-security violation restrict
switchport port-security mac-address sticky

spanning-tree portfast edge
spanning-tree bpduguard enable

no shutdown
Ethernet1/0 — Marketing

Este puerto conecta el equipo correspondiente al departamento de Marketing mediante la VLAN 70.

interface Ethernet1/0

description PC_MARKETING

switchport access vlan 70

switchport nonegotiate

🔒 7. Acceso administrativo

El acceso administrativo utiliza la cuenta local admin.

Consola
line con 0

logging synchronous
login local
exec-timeout 5 0
VTY / SSH

Las líneas VTY están configuradas para aceptar únicamente conexiones mediante SSH.

line vty 0 4

login local
transport input ssh
exec-timeout 5 0
