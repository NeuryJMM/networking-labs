SW-10 — Acceso Santo Domingo

AEGIS SOLUTIONS
Configuración del switch de acceso correspondiente a la sede de Santo Domingo.

📋 Información general
Parámetro	Valor
Dispositivo	SW-10
Rol	Switch de acceso
Ubicación	Santo Domingo
Dominio	aegis.com.do
SSH	Versión 2
Spanning Tree	Rapid-PVST
VLAN nativa	VLAN 99

##🔐 1. Configuración básica y seguridad

Esta sección establece el nombre del dispositivo, autenticación administrativa, dominio, SSH y cifrado de contraseñas.

enable
configure terminal

hostname SW-10

service timestamps debug datetime msec
service timestamps log datetime msec
service password-encryption

enable secret AEGIS-2026

username admin privilege 15 secret AEGIS-2026

no ip domain-lookup
ip domain-name aegis.com.do

ip ssh version 2
ip ssh time-out 60

crypto key generate rsa modulus 2048

##🛡️ 2. Compatibilidad DHCP / IOL / PNETLab

Se deshabilitan estas funciones para evitar problemas de compatibilidad con el entorno de laboratorio IOL/PNETLab.

no ip dhcp snooping
no ip dhcp snooping information option
no ip arp inspection vlan 10,20,99
🏢 3. VLANs locales

El switch utiliza tres VLANs:

VLAN	Nombre	Función
10	DIR_GENERAL	Dirección General
20	RRHH	Recursos Humanos
99	NATIVA	VLAN nativa de los enlaces troncales
Configuración
vlan 10
 name DIR_GENERAL

vlan 20
 name RRHH

vlan 99
 name NATIVA

exit

##🌳 4. Spanning Tree

Se utiliza Rapid-PVST para mejorar la convergencia de la red ante cambios en la topología.

spanning-tree mode rapid-pvst
spanning-tree extend system-id

##🔗 5. Enlaces troncales

Los puertos Ethernet0/0 y Ethernet0/1 funcionan como enlaces troncales hacia los switches multicapa SWM-1 y SWM-2.

Características
Protocolo: 802.1Q
VLANs permitidas: 10,20,99
VLAN nativa: 99
DTP: deshabilitado
Estado: habilitado
Configuración
interface range Ethernet0/0 - 1

description UPLINKS-MULTICAPA

switchport trunk encapsulation dot1q
switchport trunk allowed vlan 10,20,99
switchport trunk native vlan 99
switchport mode trunk
switchport nonegotiate

no shutdown


Ethernet0/2 — Dirección General

Este puerto conecta el equipo correspondiente a Dirección General mediante la VLAN 10.

interface Ethernet0/2

description PC_DIR_GENERAL

switchport access vlan 10
switchport mode access
switchport nonegotiate

switchport port-security
switchport port-security maximum 2
switchport port-security violation restrict
switchport port-security mac-address sticky

spanning-tree portfast edge
spanning-tree bpduguard enable

no shutdown
Ethernet0/3 — Recursos Humanos

Este puerto conecta el equipo correspondiente a Recursos Humanos mediante la VLAN 20.

interface Ethernet0/3

description PC_RRHH

switchport access vlan 20
switchport mode access
switchport nonegotiate

switchport port-security
switchport port-security maximum 2
switchport port-security violation restrict
switchport port-security mac-address sticky

spanning-tree portfast edge
spanning-tree bpduguard enable

no shutdown

##🔒 7. Acceso administrativo

El acceso administrativo se realiza mediante la cuenta local admin.

Consola
line con 0

logging synchronous
login local
exec-timeout 5 0
VTY / SSH

Las líneas VTY únicamente permiten conexiones mediante SSH.

line vty 0 4

login local
transport input ssh
exec-timeout 5 0

##⚠️ 8. Banner de seguridad

Se configura un mensaje de advertencia para informar que el dispositivo es de acceso restringido.

banner motd #

------------------------------------------------------------
AEGIS SOLUTIONS - SEDE SANTO DOMINGO

ADVERTENCIA:
ACCESO RESTRINGIDO.

Toda actividad en este dispositivo esta siendo monitorizada.
------------------------------------------------------------

#

##💾 9. Guardar configuración

Finalmente, se guarda la configuración en la memoria del dispositivo.

end
write memory

🔎 11. Comandos de verificación

Después de aplicar la configuración, puedes comprobar el estado del switch con:

show running-config
show vlan brief
show interfaces trunk
show spanning-tree
show port-security
show port-security interface Ethernet0/2
show port-security interface Ethernet0/3
show ip ssh
show users
Verificación de conectividad
ping <IP_DEL_DESTINO>
